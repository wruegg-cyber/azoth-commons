# GPT Start Here

This public repository is read-only reference context for the initial History workflow.

Use it to understand planned AZOTH repository boundaries, extraction standards, access policy, and the future separation of the Historical Operating System from its eventual game.

Do not assume that a catalog entry means a project is already public or ready. Each extraction still needs a rights review, a clean-clone install and test, an honest README, and owner approval.

Do not request access to the private workshop merely to search broadly. If History work needs a specific private artifact, identify the exact question and allow the owner or Codex to prepare a bounded, reviewed packet.

The designated History-writing GPT should write only in the private History repository and treat this repository as public reference material.
